# Homelab Inventory System

A learning-focused project to design, build, document, and deploy a web-based inventory system for personal homelabs.

## Goals

- Track computers, laptops, servers, consoles, and related equipment.
- Practice relational database design and SQL.
- Build a web interface using HTML/CSS and Python.
- Integrate the application through SQL.
- Practice Git, testing and documentation.

## What's used

- Python
- Flask
- HTML and CSS
- SQL
- Ubuntu Server for eventual deployment
